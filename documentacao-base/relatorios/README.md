# Relatórios e Pesquisa

Esta pasta contém relatórios, notas e materiais de pesquisa relacionados à ferramenta desenvolvida neste repositório.

Estrutura sugerida:

- `relatorios/relatorio-<ano>-<tema>.md` — relatórios formais.
- `relatorios/notes/` — notas, ideias e rascunhos.
- `relatorios/data/` — dados usados em análises e experimentos (quando aplicável).

Use esta pasta para centralizar toda a documentação de pesquisa e resultados experimentais.
