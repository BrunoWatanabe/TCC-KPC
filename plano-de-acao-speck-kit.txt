# 🚀 Roadmap do Projeto — Spec-Kit

## 📌 Visão Geral

O projeto tem como objetivo criar um framework experimental para:

- Spec-Driven Development (SDD)
- Model-Driven Engineering (MDE)
- Agentes assistidos por IA
- Avaliação de alinhamento entre modelagem e implementação

A proposta central é permitir que:

```text
especificação ↔ modelo ↔ código ↔ testes
```

permaneçam alinhados durante o desenvolvimento.

---

# 🧠 Ideia Central do Projeto

O projeto propõe uma metodologia onde:

| Papel | Responsabilidade |
|---|---|
| Agente Arquiteto | cria especificações e modelos |
| Agente Desenvolvedor | implementa funcionalidades |
| Agente QA | valida alinhamento |

Tudo isso apoiado por:
- GitHub Copilot
- PlantUML
- GitHub Actions
- métricas de alinhamento
- rastreabilidade entre artefatos

# 📊 FASE 5 — Métricas de Alinhamento

## 🎯 Objetivo

Transformar alinhamento em métricas mensuráveis.

---

## ✅ Métricas principais

### 1. Cobertura do modelo

```text
elementos implementados / elementos modelados
```

---

### 2. Precisão da implementação

```text
implementações corretas / implementações totais
```

---

### 3. Divergência semântica

Detectar:
- regras quebradas
- comportamento divergente

---

### 4. Over-engineering

```text
código sem representação no modelo
```

---

### 5. Score geral de alinhamento

Combinar:
- cobertura
- precisão
- divergência
- inconsistências
